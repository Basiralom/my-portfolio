# Basir Alom — Full Stack Developer Portfolio

A responsive, multi-page personal portfolio made with plain HTML, CSS, and JavaScript. No build tools or backend are required to preview the pages.

## Pages
- `index.html` — Home / introduction
- `about.html` — About and working approach
- `skills.html` — Frontend, backend, database, and developer tools
- `projects.html` — Project showcase
- `services.html` — Services / areas of interest
- `contact.html` — Contact form that prepares an email after configuration

## Run locally
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Use the navigation to move between separate pages.

## Before publishing
1. Open `script.js` and replace `YOUR_EMAIL@example.com` with your real email address.
2. In `contact.html`, replace “Replace with your email” and add your actual GitHub, LinkedIn, and other profile links.
3. In `projects.html` and the homepage, replace concept projects with real work; add working demo and source-code links when available.
4. In `skills.html`, remove any technology you have not started learning and adjust the list to match your actual experience.
5. Update the page title, description, and contact details if needed.
6. Test all pages on mobile and desktop.

## Hosting
This is a static frontend. You can deploy it to Hostinger static hosting, Vercel, Netlify, or GitHub Pages without a backend. The contact form currently uses `mailto:` (opens the visitor's email app); it does not store submissions. To receive form submissions directly, connect a form service or build a backend/API.

## Notes
- Photos are stored locally in `assets/`, so they travel with the website.
- Google Fonts are used for typography; if the visitor is offline, fallback fonts will be used.
- Project entries are clearly presented as concepts / work-in-progress, not as claims of completed production deployments.
